# hamid.com

The Conference of the Birds: a landing page with 30 animated birds.

Published with GitHub Pages from the main branch root at https://hamid.com.

To rebuild after editing the flight rig or shoulder placements:

```sh
node build-realistic-flock.mjs
```

Commit the rebuilt index.html and conference-of-the-birds.svg together with the source changes. The two PNG atlases supply the body and wing artwork.
